# IPL DATA ANALYSIS

## Project Title
IPL Data Analysis

## Objective
The objective of this project is to analyze IPL match data and identify important patterns and trends related to teams, players, runs, wickets, toss decisions, venues, and seasons.

## Dataset
The dataset contains IPL match and ball-by-ball information.

Important columns include:
- Match_ID
- Season
- Match_Date
- City
- Venue
- Team1
- Team2
- Toss_Winner
- Toss_Decision
- Winner
- Runs_Scored
- Wickets
- Batsman
- Bowler
- Player_of_Match

## Tools & Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Power Query
- DAX
- Google Colab
- GitHub

## Analysis Performed
- Data cleaning and preprocessing
- Checked missing values and duplicate records
- Analyzed team wins
- Analyzed matches by season
- Analyzed toss decisions
- Analyzed top run scorers
- Analyzed top wicket takers
- Analyzed Player of the Match awards
- Analyzed venue-wise matches
- Analyzed season-wise runs and wickets
- Analyzed team performance

## Dashboard
A Power BI dashboard was created to visualize:
- Matches by Season
- Team Wins
- Top 10 Batsmen
- Top 10 Bowlers
- Runs by Season
- Matches by Venue
- Toss Decision
- Player of the Match
- Team Performance
- Season, Team, and Venue filters

## Key Insights
- Team-wise win performance was analyzed.
- Season-wise match and run trends were identified.
- Top batsmen and bowlers were identified.
- Toss decision patterns were analyzed.
- Venue-wise match distribution was analyzed.
- Player of the Match performance was analyzed.

## Conclusion
This project demonstrates how Python and Power BI can be used together for IPL data analysis. The analysis helps identify team performance, player performance, season trends, toss patterns, and venue trends using data visualization and analytics.
